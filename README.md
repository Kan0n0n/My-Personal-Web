# Philine’s Picture Book

A small personal web app inspired by cozy, handmade websites of the early 2010s. Warm paper textures, handwritten lettering, gingham borders and familiar characters frame a little home for everyday life and favorite stories.

Keep daily notes, write blogs and stories, collect useful links, organize tasks and reminders, and record anime progress and personal ratings. A private reading room holds TXT, Markdown, EPUB and PDF books, with series folders, remembered reading positions and read-aloud through installed device voices.

Share selected writing and anime logs publicly while keeping your notebook and library private. Music of the Day adds a public soundtrack, and the archive follows the app’s changes over time. Small utilities include a choice picker, a text counter and a diagram-analysis interface for a separate service.

Built with **React, Node.js, Express, Tailwind CSS and PostgreSQL**, while preserving its original artwork and decorative CSS.
