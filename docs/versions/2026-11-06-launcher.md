# Version 2.0.5 — One-click startup

Added a Windows double-click launcher that reads existing configuration, starts Docker Desktop and the local Compose database when needed, checks schema access, starts the app, and opens the configured home page. An existing app can be reopened without a second server. Startup errors stay visible. Setup and migrations remain explicit one-time/upgrade operations.

Added a daily-use guide with pgAdmin connection settings, table descriptions, and SQL inspection examples. Database credentials are never printed by the launcher.

Verified configuration checking, live startup against the existing local PostgreSQL database, HTTP 200 for the home page, and reopening an existing server using `--no-browser`. All 35 frontend/static, 13 embedded database/API, and 7 mocked music API scenarios passed. Docker Desktop and Compose startup were verified separately. Automatic browser opening and the complete double-click path after a Windows reboot were not exercised.
