# 1.0.0 — A picture book finds its pages again

The first rebuilding pass, based on the surviving `ultilities.html`, fonts, and illustrations.

## Added

- A responsive home with introduction, status, current interests, local music, calendar reminders, and optional weather.
- Daily life entries, blog/story entries, teaching-resource links, work tasks, and anime thoughts with personal heart ratings.
- TXT/Markdown novel import from selected local folders or files; browser-local library, reading controls, and bookmarks.
- Full notebook and novel backup/restore.
- A public snapshot export for profile, daily notes, blogs/stories, and anime logs; private notebook sections are excluded.
- A version archive fed by `CHANGELOG.json`.

## Preserved

The original utility, script, styles, and artwork. A small navigation bar and backend availability note were added to the utility page.

## Limits

This is a local-first static site. Browser edits do not publish for other visitors. There is no login, cloud sync, document upload, or direct cloud API connection yet. Use document links in the meantime. Novel import copies text into IndexedDB; it does not monitor the folder. EPUB/PDF parsing is not included. Audio selection lasts for the page session. The original diagram backend was not present and must be restored separately.

Update this file and the JSON archive when changing the code. The archive does not infer changes automatically.

## Verification

`node --check scripts/picturebook.js` and `node --check scripts/serve.mjs` passed. `node scripts/check.mjs --http` passed 27 checks covering route rendering in a lightweight DOM stub, linked asset paths, unsafe URL rejection, malformed backup rejection, entry create/edit persistence, archive notes, and HTTP availability of all ten pages.

Browser automation was unavailable in this environment. Visual layout, responsive behavior, native file/folder selection, IndexedDB interactions, actual audio playback, live geolocation/weather, and full backup/restore still need an interactive browser review. The lightweight checks do not simulate those browser facilities.
