# 1.1.0 — Back to an anime homepage

Date: 5 November 2026.

## Why

The first rebuild’s spacious scrapbook appearance did not match the owner’s intended older anime/indie-web feeling. The owner requested the original animated logo behaviour, responsive layout, a tidier project, a complete technical/visual report, and a future plan.

## Changes

- Replaced the active theme with a gingham/lace frame, compact sidebar directory, starry banner, multicoloured handwritten logo, dotted borders, pale gradient headings, and white content panels.
- Restored a staggered jumping name on hover/focus/press and character-image zoom. Added reduced-motion overrides.
- Added explicit desktop/tablet/phone and touch-capability rules. The calendar appears on all main pages; on phones it follows the main content.
- Moved actual HTML into `pages/`, runtime assets into `assets/`, archive data into `data/`, and checks into `tests/`. Kept a single root entry redirect. The local server redirects old flat HTML URLs.
- Restyled the extractor without changing its backend endpoint; added responsive results, safer filename/JSON insertion, busy-state cleanup, and keyboard closing for its image viewer.
- Retained former styles as historical references, and archived the previous extractor HTML as text.
- Added the project report, full function/callback reference, and prioritised update plan.

## Data compatibility

`philine-picturebook-v1` and `philine-books` remain unchanged. Page moves do not change the browser origin. Continue using the same scheme, host, and port to keep existing local data visible.

## Verification

JavaScript syntax checks passed for both browser scripts, the server, and the test file. `node tests/check.mjs` passed 30 checks; with the server running, `node tests/check.mjs --http` passed 52 checks. Coverage includes local route/asset references, generated links, logo markup, entry persistence, archive note paths, HTTP pages, redirects, and error responses. See the project report and README for commands.

Browser automation was unavailable. Responsive visuals, real device interaction, audio/weather, folder import, IndexedDB workflows, and full backup/restore need an interactive browser review. The absent extractor backend was not tested end-to-end.
